## 构造函数
| 构造函数类型         | 示例代码                                    | `size` 结果   | `capacity` 结果     | 关键特性                                                                              |     |
| -------------- | --------------------------------------- | ----------- | ----------------- | --------------------------------------------------------------------------------- | --- |
| **默认构造**       | `vector<int> v1;`                       | `0`         | `0`（标准未强制，但通常为 0） | 不分配任何堆内存。                                                                         |     |
| **指定数量（值初始化）** | `vector<int> v2(5);`                    | `5`         | `>= 5`            | 元素被**值初始化**（int 为 0，类类型调用默认构造）。**此构造函数是 `explicit` 的**，即不能写 `vector<int> v = 5;`。 |     |
| **指定数量+初始值**   | `vector<int> v3(5, 10);`                | `5`         | `>= 5`            | 5 个元素全部初始化为 10。                                                                   |     |
| **迭代器范围**      | `vector<int> v4(v3.begin(), v3.end());` | `5`         | `>= 5`            | 拷贝范围内的元素，容量通常恰好等于大小（不保证多余空间）。                                                     |     |
| **拷贝构造**       | `vector<int> v5(v3);`                   | `5`         | `>= 5`            | 深拷贝所有元素，容量通常等于源对象的 `size`（具体由分配器决定）。                                              |     |
| **移动构造**       | `vector<int> v6(std::move(v3));`        | `v3` 变为 `0` | 窃取 `v3` 的内存指针     | **不分配新内存**，直接把 v3 的内存拿过来，极高效。                                                     |     |
| **初始化列表**      | `vector<int> v7{1, 2, 3};`              | `3`         | `>= 3`            | 优先匹配 `initializer_list` 重载。                                                       |     |
## reserve

**作用**：仅负责**扩大**容器的 `capacity`，**绝不改变** `size`，**绝不构造**任何新元素。

- **语法**：`v.reserve(n);`
    
- **执行逻辑**：
    
    1. 如果 `n <= v.capacity()`：**什么都不做**（耗时 O(1)）。
        
    2. 如果 `n > v.capacity()`：触发**内存重新分配**。
        
        - 申请一块大小为 `n` 的新内存。
            
        - 将旧内存中的元素**移动/拷贝**（C++11 起优先移动）到新内存。
            
        - 析构旧内存中的元素并释放旧内存。
## resize
**作用**：改变容器的 `size`。如果 `size` 变化，会**构造或销毁**容器内的元素对象。

- **语法**：`v.resize(count);` 或 `v.resize(count, value);`
    
- **执行逻辑**（分三种情况）：
    
    1. **如果 `count < v.size()`（缩小）**：
        
        - 销毁末尾的 `(v.size() - count)` 个元素（调用析构函数）。
            
        - **`capacity` 保持不变**（内存不会释放，这是为了避免频繁分配释放内存的抖动）。
            
        - `size` 变为 `count`。
            
    2. **如果 `count > v.size()`（扩大）**：
        
        - 判断 `count` 是否大于 `capacity`。如果是，先触发内存重新分配（扩容规则通常是 2 倍或 1.5 倍，也可能精确扩展）。
            
        - 在末尾追加 `(count - v.size())` 个**新构造**的元素。
            
            - 如果提供了 `value`，则拷贝构造这些新元素。
                
            - 如果未提供，则进行**值初始化**（基本类型补 0，类类型调用默认构造函数）。
                
        - `size` 变为 `count`。
            
    3. **如果 `count == v.size()`**：什么都不做。
