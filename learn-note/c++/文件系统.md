## path
### operator/进行拼接
```cpp
#include <filesystem>

namespace fs = std::filesystem;

auto main() -> int {
  fs::path p = "/path";
  p /= "usr";
  auto p2 = p / "bin";
  return 0;
}
```
### 分解路径
```cpp
#include <filesystem>
#include <print>

namespace fs = std::filesystem;

auto main() -> int {
  fs::path p = "/path/text.txt";
  std::println("filename:{}\nstem:{}\nparent_path:{}\nextention:{}",
               p.filename().string(), p.stem().string(),
               p.parent_path().string(), p.extension().string());
  return 0;
}
```
## 状态查询
```cpp
fs::exists(p);            // 路径是否存在  
fs::is_regular_file(p);   // 是否为常规文件  
fs::is_directory(p);      // 是否为目录  
fs::file_size(p);         // 文件大小（字节）  
fs::last_write_time(p);   // 最后修改时间
```
**抛出 `std::filesystem::filesystem_error` 异常**，但如果不抛异常可使用`error_code`：
```cpp
std::error_code ec;  <br>auto size = fs::file_size(p, ec); // 出错时不抛异常，错误写入 ec
if (ec) {
	std::cout << "无法获取大小：" << ec.message() << std::endl;  
}
```
## 遍历目录
```cpp
for (const auto& entry : fs::directory_iterator(dir)) {  
    std::cout << entry.path() << std::endl;  
}  
  
// 递归遍历整棵目录树  
for (const auto& entry : fs::recursive_directory_iterator(dir)) {  
    if (entry.is_regular_file())  
        std::cout << entry.path() << " (" << entry.file_size() << ")\n";  
}
```
## 创建删除复制
```cpp
fs::create_directories(p / "a" / "b"); // 递归创建目录（中间目录不存在时一并创建）  
fs::copy_file(src, dst);               // 复制单个文件  
fs::copy(src, dst, fs::copy_options::recursive); // 递归复制目录  
fs::rename(old_path, new_path);        // 重命名 / 移动  
fs::remove(p);                         // 删除单个文件或空目录  
fs::remove_all(p);                     // 递归删除，返回被删除的条目数
```
