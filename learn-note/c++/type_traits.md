| 分类      | 性状                              | 一句话作用                                  | 什么时候用                           |
| ------- | ------------------------------- | -------------------------------------- | ------------------------------- |
| **修改型** | **`decay_t<T>`**(详细[[decay]])   | **万能擦除器**：去除引用/cv，数组变指针，函数变指针          | 模板里拿到类型后想“干净地”存进容器时，**必用**      |
| **修改型** | **`remove_reference_t<T>`**     | 只去掉`&`和`&&`，保留const                    | 万能引用`T&&`配合`decltype`时，用来获取原始类型 |
| **关系型** | **`is_same_v<T,U>`**            | 两个类型是否**完全一样**                         | 做类型特化分支、调试时打印类型名称               |
| **关系型** | **`is_base_of_v<B,D>`**         | 判断继承关系（含私有/虚继承）                        | 检查是否可安全地基类指针指向派生类               |
| **关系型** | **`is_convertible_v<From,To>`** | 能否**隐式转换**（含构造函数和转换运算符）                | 检查参数能否互相赋值，比`is_base_of`更宽松     |
| **分类型** | **`is_integral_v<T>`**          | 是不是整型（int/char/bool等）                  | 数学库限制输入，拒绝浮点和字符串                |
| **分类型** | **`is_class_v<T>`**             | 是不是`class/struct`（不含联合体）               | 序列化时区分基础类型和自定义对象                |
| **计算型** | **`common_type_t<T,U>`**        | 找出`T`和`U`的**公共类型**（如int+double→double） | 写加法/比较运算符模板，推导返回值类型             |
